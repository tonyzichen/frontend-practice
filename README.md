# 个人主页与杭州介绍项目 (Personal Portfolio & Hangzhou Intro)

欢迎来到我的个人前端项目仓库！本仓库整合了我的个人介绍与城市介绍两个核心项目。所有页面均采用**纯 HTML5** 编写，未依赖任何 CSS 样式和 JavaScript 脚本，旨在通过最基础、最纯粹的代码展示良好的网页结构与语义化标签运用能力。

##  项目目录

本仓库包含以下两个主要部分：

### 1. 个人自我介绍 (Self-Introduction)
一个展示我个人背景与技术栈的专属页面。
- **核心内容**：涵盖个人基本信息、教育背景、核心技术栈以及过往的项目经历。
- **技术亮点**：使用 `<header>`, `<section>`, `<article>` 等语义化标签构建页面，结构清晰，零依赖。

### 2. 杭州城市介绍 (Hangzhou-Introduction)
一个全方位展示杭州魅力的图文网页。
- **核心内容**：详细介绍了杭州的城市概况、历史底蕴、著名风景名胜（如西湖、良渚古城等）以及现代数字经济的发展活力。
- **技术亮点**：综合运用标题层级、无序列表 (`<ul>`)、数据表格 (`<table>`)、图片 (`<img>`) 与超链接 (`<a>`) 等多种 HTML 基础元素，排版丰富且规范。
